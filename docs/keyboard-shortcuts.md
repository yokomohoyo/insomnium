# Keyboard shortcuts

Change any of these in **Preferences → Keyboard** (Ctrl+Shift+/, or ⌃⇧⌘/ on macOS): each one's menu adds another key combination or resets it, and **Reset all** puts them all back.

| Action | Windows and Linux | macOS |
|---|---|---|
| Send request | Ctrl+Enter, Ctrl+R, F5 | ⌘Enter, ⌘R, F5 |
| Send request (options) | Ctrl+Shift+Enter | ⇧⌘Enter |
| Switch requests (quick switcher) | Ctrl+P | ⌘P |
| Show recent requests | Ctrl+Tab | ⌃Tab |
| Show recent requests (previous) | Ctrl+Shift+Tab | ⌃⇧Tab |
| Create HTTP request | Ctrl+N, Ctrl+Alt+N | ⌘N, ⌥⌘N |
| Create folder | Ctrl+Shift+N | ⇧⌘N |
| Duplicate request | Ctrl+D | ⌘D |
| Delete request | Ctrl+Shift+Delete | ⇧⌘Delete |
| Pin or unpin request | Ctrl+Shift+P | ⇧⌘P |
| Focus URL | Ctrl+L | ⌘L |
| Change HTTP method | Ctrl+Shift+L | ⇧⌘L |
| Show request history | Ctrl+Shift+H | ⇧⌘H |
| Show request settings | Ctrl+Alt+Shift+, | ⌥⇧⌘, |
| Generate code | Ctrl+Shift+G | ⇧⌘G |
| Focus response | Ctrl+' | ⌘' |
| Beautify code editors | Ctrl+Shift+F | ⇧⌘F |
| Filter sidebar | Ctrl+Shift+F | ⇧⌘F |
| Toggle sidebar | Ctrl+\ | ⌘\ |
| Show environment editor | Ctrl+E | ⌘E |
| Switch environments | Ctrl+Shift+E | ⇧⌘E |
| Show a variable's source and value | Alt+Shift+U | ⌥⇧U |
| Show autocomplete | Ctrl+Space | ⌃Space |
| Edit cookies | Ctrl+K | ⌘K |
| Focus GraphQL explorer filter | Ctrl+Shift+I | ⇧⌘I |
| Collection or document settings | Ctrl+Shift+, | ⇧⌘, |
| Preferences | Ctrl+, | ⌘, |
| Keyboard shortcuts | Ctrl+Shift+/ | ⌃⇧⌘/ |
| Reload plugins | Ctrl+Shift+R | ⇧⌘R |

The quick switcher (Ctrl+P) searches the collection's requests: type words from a request's name, URL or folder. Ctrl+Tab lists them by when you last opened them, starting on the one before, so Ctrl+Tab then Enter goes back.
